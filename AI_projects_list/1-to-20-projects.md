# 1. AI-Based Disease Risk Prediction System

## Domain

Healthcare + Artificial Intelligence

## Abstract

Predicts disease probability (diabetes, heart disease, kidney disorders) using ML models trained on patient data like age, BP, glucose, cholesterol, BMI, and lifestyle habits.

## Existing System

* Manual diagnosis
* Human-dependent decision
* No automated risk prediction

## Proposed System

* ML-based risk prediction
* Faster and more accurate
* Preventive healthcare support

## System Requirements

### Hardware

* Intel i5 / Ryzen 5
* 8 GB RAM
* 20 GB Storage

### Software

* Windows / Linux / macOS
* Python 3.9+
* VS Code / PyCharm / Jupyter
* CSV / SQLite

## Algorithms

* Logistic Regression
* Random Forest

## Libraries

* pandas
* numpy
* scikit-learn
* matplotlib
* seaborn

## Learning Outcomes

* Medical data analysis
* Classification models
* Ethical AI usage
