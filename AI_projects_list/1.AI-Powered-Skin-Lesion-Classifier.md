## Project 1: AI-Powered Skin Lesion Classifier

### Project Abstraction

Early detection of skin conditions like melanoma or basal cell carcinoma can significantly improve patient outcomes. This project involves building a deep learning model (Convolutional Neural Network) trained on a dataset like **HAM10000**.

The application allows a user to upload a clear photograph of a skin lesion via a mobile or desktop browser. The backend processes the image, runs it through the trained model, and provides a probability-based classification (e.g., "78% likelihood of Nevus"). To ensure professionalism, the output should always include a **medical disclaimer** stating that the tool is for screening assistance and not a final diagnosis.
