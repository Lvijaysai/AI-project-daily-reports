## Project 1: AI-Powered Skin Lesion Classifier

### Project Abstraction

Early detection of skin conditions like melanoma or basal cell carcinoma can significantly improve patient outcomes. This project involves building a deep learning model (Convolutional Neural Network) trained on a dataset like **HAM10000**.

The application allows a user to upload a clear photograph of a skin lesion via a mobile or desktop browser. The backend processes the image, runs it through the trained model, and provides a probability-based classification (e.g., "78% likelihood of Nevus"). To ensure professionalism, the output should always include a **medical disclaimer** stating that the tool is for screening assistance and not a final diagnosis.

### Hardware Requirements

* **Development Phase:**
* **CPU:** Intel i5/AMD Ryzen 5 (8GB RAM minimum).
* **GPU (Highly Recommended):** NVIDIA GPU with CUDA support (e.g., GTX 1650 or higher) for faster model training. Alternatively, students can use **Google Colab** (Free Cloud GPU).


* **Deployment Phase:**
* A standard smartphone with a high-resolution camera for capturing/uploading images.
* A basic cloud server (like a Free Tier instance on AWS or Render).



### Simple Tech Stack

* **Language:** Python 3.9+
* **Deep Learning Framework:** **TensorFlow/Keras** (beginner-friendly) or **PyTorch**.
* **Web Framework:** **Streamlit** (This is the simplest way to turn a Python script into a professional web app without needing HTML/CSS/JS).
* **Image Processing:** **OpenCV** or **Pillow** (for resizing and normalizing user uploads).
* **Dataset:** **HAM10000** (Available on Kaggle; contains 10,000+ labeled images of skin lesions).
