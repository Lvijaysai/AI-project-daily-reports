## Project 2: Mental Health Sentiment Monitor

---

### Project Abstraction

The **Mental Health Sentiment Monitor** is a digital "Mood Journal" that helps users identify emotional patterns over time. Instead of just storing text, the application uses **Natural Language Processing (NLP)** to analyze the sentiment and emotional intensity of each entry.

The system tracks shifts in vocabulary—such as an increase in "absolute" words (always, never, completely) or a decrease in positive-sentiment verbs—which can be early indicators of burnout or depressive episodes. The professional "startup" angle is the **Visual Dashboard**, which provides weekly "Emotional Health Reports" and suggests proactive self-care or professional consultation when persistent negative trends are detected.

---

### Hardware Requirements

* **Developer PC:** Any standard laptop (4GB+ RAM) can handle this. No dedicated GPU is required because we will use pre-trained "lightweight" models.
* **End-User Device:** Any device with a modern web browser (Smartphone, Tablet, or Laptop).
* **Cloud Hosting:** **Free Tier** services like **Render**, **Railway**, or **Hugging Face Spaces**.

---

### Tech Stack

To keep this "professional yet simple," we will use high-level libraries that do the heavy lifting for the students.

* **Language:** **Python 3.9+**
* **Frontend & Backend (Unified):** **Streamlit**. (It allows students to build the text areas, buttons, and charts entirely in Python).
* **AI/NLP Engine:** **TextBlob** or **VADER Sentiment**.
* *Why?* These are "Rule-based" and extremely fast. They don't require heavy downloads or expensive GPUs.


* **Data Visualization:** **Plotly Express**. (To create professional, interactive line charts showing "Mood over Time").
* **Database (Optional/Simple):** **SQLite**. (It is a file-based database that comes built-in with Python—no setup required).
* **Deployment:** **Streamlit Community Cloud**. (Completely free hosting for Streamlit apps directly from a GitHub repository).

---

### Key Student Milestone: "The Privacy Shield"

To make this professional, students should implement a "Local-First" approach:

> "Your data is analyzed on this session and never sold. We use lightweight models to ensure your private thoughts stay private."
