## Project 6: E-commerce Visual Search ("Snap & Shop")

### Project Abstraction

The **E-commerce Visual Search** tool allows users to find products without using words. Instead of typing "blue floral summer dress," a user simply uploads an image of an outfit they saw on social media or in real life.

The AI doesn't just "label" the image; it converts the image into a mathematical vector (an "embedding") that represents the style, pattern, and color. The system then calculates the "distance" between this vector and a pre-indexed catalog of products, returning the top 5 most similar items. This is a professional-grade project that teaches students how to handle image databases and recommendation logic.
