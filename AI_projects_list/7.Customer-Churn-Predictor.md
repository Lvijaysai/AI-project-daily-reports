## Project 7: Customer Churn Predictor

### Project Abstraction

The **Customer Churn Predictor** is a strategic dashboard designed for startup founders. "Churn" occurs when a customer cancels their subscription. This project uses machine learning to analyze user behavior—such as login frequency, support ticket history, and feature usage—to assign a "Churn Probability" score to every user.

The system classifies users into risk tiers (High, Medium, Low). To make this a "professional" startup tool, the project doesn't just predict *who* will leave; it provides **Actionable Insights**, such as "User hasn't logged in for 10 days; suggest a 20% discount email."
