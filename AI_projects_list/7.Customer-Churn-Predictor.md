## Project 7: Customer Churn Predictor

### Project Abstraction

The **Customer Churn Predictor** is a strategic dashboard designed for startup founders. "Churn" occurs when a customer cancels their subscription. This project uses machine learning to analyze user behavior—such as login frequency, support ticket history, and feature usage—to assign a "Churn Probability" score to every user.

The system classifies users into risk tiers (High, Medium, Low). To make this a "professional" startup tool, the project doesn't just predict *who* will leave; it provides **Actionable Insights**, such as "User hasn't logged in for 10 days; suggest a 20% discount email."

### Hardware Requirements

* **Development Phase:**
* **CPU:** Any standard laptop (4GB+ RAM).
* **Software:** Python environment (VS Code or Jupyter Notebook).



### Simple & 100% Free Tech Stack

We will stick to a "Clean Data" approach using the most popular Python libraries for business analytics.

* **Language:** **Python 3.9+**
* **Machine Learning Library:** **Scikit-learn**.
* *Algorithm:* Use **Random Forest** or **Logistic Regression**. They are easy to explain to business stakeholders and very effective for churn.


* **UI/Frontend:** **Streamlit**.
* *Why?* Streamlit can create professional-looking sidebar filters, metric cards (e.g., "Total Churn Rate: 12%"), and data tables with zero CSS.


* **Data Manipulation:** **Pandas**.
* **Visualizations:** **Plotly** or **Altair**. (These create interactive charts where users can hover over data points to see details).
* **Dataset:** **Telco Customer Churn** dataset (available for free on **Kaggle**). It is the industry-standard "clean" dataset for this project.
