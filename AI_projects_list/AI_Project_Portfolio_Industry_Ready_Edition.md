## Project 1: AI-Powered Skin Lesion Classifier (CNN + Transfer Learning)

**Domain:** Machine Learning / Computer Vision / Healthcare
**Tech Stack Suggestion:** React or Streamlit (Frontend) + FastAPI (Backend) + TensorFlow/Keras (CNN Model) + Docker + Render/AWS EC2 (Deployment)
**Skills Covered:** Convolutional Neural Networks, Transfer Learning (ResNet/EfficientNet), Image Preprocessing, Data Augmentation, REST API Development, Model Serving, Responsive UI Design
**Dataset Availability:** Public dataset available — HAM10000 (Harvard Dataverse), ISIC Archive (International Skin Imaging Collaboration)

**Abstract:**Sri Sathya Sai Skill Development Training Program, RR District
Early detection of skin conditions like melanoma, basal cell carcinoma, and dermatofibroma can significantly improve patient outcomes and reduce mortality rates. This project involves building a deep learning model using Convolutional Neural Networks (CNNs) trained on the widely available HAM10000 dataset, which contains over 10,000 dermatoscopic images across seven diagnostic categories. Students will implement transfer learning using pre-trained architectures such as ResNet-50 or EfficientNet-B3, fine-tuning them on the skin lesion dataset to achieve high classification accuracy. The application allows a user to upload a clear photograph of a skin lesion via a mobile or desktop browser. The backend processes the image through preprocessing pipelines (resizing, normalization, augmentation), runs inference through the trained model, and provides a probability-based classification (e.g., "78% likelihood of Melanocytic Nevus"). The frontend features a clean upload interface, a results dashboard showing class probabilities as bar charts, and a history panel for past scans. To ensure professionalism, the output always includes a medical disclaimer stating that the tool is for screening assistance and not a final diagnosis. Students will learn end-to-end ML pipeline development—from data preprocessing and model training to REST API integration and cloud deployment—making this project highly resume-worthy for healthcare AI roles.

**Skills Covered:** Feature Engineering, Classification Algorithms, Explainable AI (XAI), SHAP Values, Data Preprocessing, Imbalanced Data Handling, Dashboard Design, Risk Scoring Systems
**Dataset Availability:** Public datasets available — Lending Club Dataset (Kaggle), German Credit Dataset (UCI), Home Credit Default Risk (Kaggle); synthetic alternative data can be generated

**Abstract:**
The Micro-Lending Credit Scorer is a predictive analytics tool designed for "thin-file" borrowers—unbanked individuals who lack traditional credit histories. Traditional banks reject these applicants due to the absence of CIBIL/FICO scores, leaving millions financially excluded. This project builds a machine learning model that evaluates Alternative Data—such as the consistency of utility bill payments (electricity, water, mobile recharge), mobile top-up patterns, employment stability indicators, and behavioral metadata—to generate a proprietary "Trust Score" ranging from 0 to 100. This project teaches students real-world FinTech concepts including credit risk modeling, regulatory fairness considerations, and model interpretability—essential for data science roles in banking and financial services.

## Project 6: E-commerce Visual Search — Snap & Shop (CNN Embeddings + FAISS)

**Domain:** Computer Vision / Recommendation Systems / E-commerce
**Tech Stack Suggestion:** React (Frontend) + FastAPI (Backend) + PyTorch/TensorFlow (Feature Extraction) + FAISS/Annoy (Vector Similarity Search) + ResNet/EfficientNet (Embeddings) + AWS S3 (Image Storage) + Docker + Render (Deployment)
**Skills Covered:** Image Embeddings, Transfer Learning, Vector Similarity Search, FAISS Indexing, REST API Development, Image Database Management, E-commerce UX Design, Scalable Search Architecture
**Dataset Availability:** Public datasets available — DeepFashion Dataset, Stanford Online Products, Fashion Product Images (Kaggle), Polyvore Outfit Dataset

**Abstract:**
The E-commerce Visual Search tool (branded as "Snap & Shop") allows users to find products without using text queries. Instead of typing "blue floral summer dress" and hoping for relevant results, a user simply uploads an image of an outfit they saw on social media, in a magazine, or in real life. The AI system goes beyond basic image labeling—it converts the uploaded image into a high-dimensional mathematical vector (an "embedding") using a pre-trained deep learning model such as ResNet-50 or EfficientNet. This embedding captures the visual essence of the product including style, pattern, color palette, texture, and silhouette. The system then uses vector similarity search libraries like FAISS (Facebook AI Similarity Search) or Annoy to calculate the cosine distance between the query embedding and a pre-indexed catalog of product embeddings, returning the top 5–10 most visually similar items from the catalog. The frontend presents a Pinterest-style grid of matching products with similarity scores, price information, and direct "Buy Now" links. Users can also filter results by category, price range, or color. The backend supports batch indexing of new products, making it scalable. Students will learn feature extraction using pre-trained CNNs, building and querying vector indices, handling image databases at scale, and creating responsive e-commerce interfaces. This is a professional-grade project that directly mirrors the visual search features used by companies like Pinterest, Google Lens, and Amazon StyleSnap—making it an outstanding portfolio piece for computer vision and recommendation system roles.

## Project 8: Sign Language Translator (MediaPipe + Gesture Classification)

**Domain:** Computer Vision / Deep Learning / Accessibility
**Tech Stack Suggestion:** React (Frontend) + FastAPI/Flask (Backend) + MediaPipe (Hand Landmark Detection) + TensorFlow/PyTorch (Gesture Classification) + Web Speech API / gTTS (Text-to-Speech) + WebSocket (Real-time Communication) + Docker + Render (Deployment)
**Skills Covered:** Hand Landmark Detection, Gesture Recognition, Real-time Video Processing, MediaPipe Integration, Sequence Classification, Text-to-Speech Integration, WebSocket Communication, Accessibility-First Design
**Dataset Availability:** Public datasets available — ASL Alphabet Dataset (Kaggle), Indian Sign Language Dataset, WLASL (Word-Level ASL), custom datasets collectible via MediaPipe hand landmark extraction

**Abstract:**
The Sign Language Translator is a real-time communication bridge designed to improve accessibility for the hearing and speech impaired community. Using a standard webcam, the application captures live video frames and detects hand landmarks using Google's MediaPipe framework, which identifies 21 key points on the human hand with high accuracy and low latency. These landmark coordinates are fed into a trained gesture classification model (built using LSTM, CNN, or a simple feedforward neural network) that recognizes specific gestures corresponding to the Sign Language alphabet (A–Z) or common words and phrases (e.g., "Hello," "Thank You," "Help," "Please"). Once a gesture is identified, the app displays the corresponding text on the screen in real-time and uses Text-to-Speech (TTS) via the Web Speech API or Google TTS to announce it audibly, enabling a natural flow of conversation between a sign language user and a non-signer. The frontend features a split-screen layout with the live webcam feed on one side and a transcript panel on the other, a gesture reference guide, and settings for speech speed and language preferences. Students will implement real-time video processing pipelines, learn to extract and normalize hand landmark features, train sequence classification models, integrate TTS systems, and handle WebSocket-based real-time communication for low-latency inference. This project demonstrates expertise in real-time computer vision, accessibility engineering, and human-computer interaction—making it a compelling and socially impactful portfolio piece for AI engineering roles.

## Project 9: Predictive Maintenance for Machinery (LSTM Autoencoder + Anomaly Detection)

**Domain:** Time Series / Anomaly Detection / Industrial IoT
**Tech Stack Suggestion:** React or Streamlit (Frontend) + FastAPI (Backend) + Scikit-learn / PyTorch (ML/DL Models) + Plotly/D3.js (Time Series Visualization) + Isolation Forest / LSTM Autoencoder (Anomaly Detection) + InfluxDB or PostgreSQL (Database) + Docker + Render (Deployment)
**Skills Covered:** Time-Series Analysis, Anomaly Detection, Sensor Data Processing, Feature Engineering from Signals, LSTM Autoencoders, Isolation Forest, Industrial Dashboard Design, Remaining Useful Life Estimation
**Dataset Availability:** Public datasets available — NASA Turbofan Engine Degradation (C-MAPSS), MIMII Dataset (Machine Sound), Bearing Dataset (CWRU), Predictive Maintenance Dataset (Kaggle/Microsoft)

**Abstract:**
The Predictive Maintenance system acts as a "health monitor" for industrial equipment such as motors, pumps, compressors, or fans. Instead of following costly reactive maintenance (fix after breakdown) or wasteful scheduled maintenance (replace parts on a fixed calendar), this AI-powered system analyzes Time-Series Data—specifically vibration patterns, temperature readings, sound frequencies, and operational parameters—to predict equipment failures before they occur. Machines in good condition produce a consistent operational "signature" across their sensor readings. When a bearing starts to wear out, a belt loosens, or lubrication degrades, the vibration frequency and temperature patterns shift in subtle but detectable ways. The model uses Anomaly Detection techniques such as Isolation Forest for statistical anomaly flagging or LSTM Autoencoders for learning normal operational patterns and flagging deviations. Students will train models on the NASA C-MAPSS Turbofan dataset or similar publicly available sensor datasets, learning to engineer features from raw time-series signals (rolling statistics, FFT-based frequency features, rate of change indicators). The professional output is a "Remaining Useful Life" (RUL) estimate displayed on an industrial-style dashboard, complete with equipment health gauges, trend charts for key sensor parameters, alert timelines showing when maintenance should be scheduled, and a historical log of past anomalies. Factory managers can use this dashboard to schedule repairs during non-working hours, saving thousands in lost production and emergency repair costs. Students will learn time-series feature engineering, anomaly detection algorithms, signal processing fundamentals, and industrial dashboard design—skills in high demand for manufacturing analytics, IoT, and Industry 4.0 roles.

**Skills Covered:** Named Entity Recognition, Text Similarity, Sentence Embeddings, PDF Parsing, Keyword Extraction, Semantic Search, Full-Stack Development, HR Analytics
**Dataset Availability:** Public datasets available — Resume Dataset (Kaggle), Job Descriptions Dataset (Kaggle); synthetic resume-job pairs can be generated

**Abstract:**
The AI Resume Screener & Job-Fit Analyzer automates the initial stage of the hiring pipeline—a task that typically consumes hundreds of hours for HR teams screening through thousands of applications. Recruiters paste a job description into the system, and candidates upload their resumes in PDF or DOCX format. The backend extracts text from uploaded resumes using PyPDF2 or pdfplumber, then applies NLP techniques to parse structured information: candidate name, email, education, work experience, skills, certifications, and projects. The frontend features a recruiter dashboard showing all applicants ranked by fit score, a detailed candidate profile view with highlighted matching and missing skills, a side-by-side comparison tool, and batch processing for multiple job openings. Candidates also get a self-service portal to check how well their resume matches a target job description with specific improvement suggestions. **Abstract:**
The AI Code Review Assistant is a developer productivity tool that leverages Large Language Models (LLMs) to provide intelligent, context-aware code reviews. Developers paste code snippets or connect their GitHub repositories, and the system analyzes the code for potential bugs, security vulnerabilities, performance bottlenecks, code style violations, and adherence to best practices. The backend integrates with an LLM (OpenAI's GPT-4 API for cloud deployments or Ollama with open-source models like CodeLlama or DeepSeek-Coder for self-hosted setups) through carefully engineered prompts that instruct the model to act as a senior software engineer performing a thorough code review.
